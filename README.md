# Fundamentos de JavaScript

Exercícios organizados por tema e uma simulação de estoque no terminal.

## 📌 Funcionalidades

- Estruturas básicas, condicionais e repetição.
- Desafios de lógica e arrays.
- Simulação de saída de produtos e cálculo de valor.

## Tecnologias

JavaScript, Node.js e prompt-sync.

## 🚀 Como executar

```bash
git clone https://github.com/daviddevdias/javascript-fundamentals.git
cd javascript-fundamentals
node "01_Fundamentos/Estruturas_Basicas.js"
```

Para executar a simulação:

```bash
cd 03_Projeto_Estoque_Simples
npm ci
node "New v4.js"
```

O estoque fica em memória durante a execução. Projeto de estudo, sem persistência em banco de dados.
